15. What will be the output of the following Java program?

  1.     class leftshift_operator 
  2.     {
  3.         public static void main(String args[]) 
  4.         {        
  5.              byte x = 64;
  6.              int i;
  7.              byte y; 
  8.              i = x << 2;
  9.              y = (byte) (x << 2);
  10.              System.out.print(i + " " + y);
  11.         } 
  12.     }

a) 0 256
b) 0 64
c) 256 0
d) 64 0
View Answer

Answer: c
Explanation: A variable of type int can store values within 32 bits, while a byte has only 8 bits to store any value. The expression (64 << 2) results in 256, which requires at least 9 bits to represent. Therefore:

  • For byte: The 9th bit is lost (truncated), and the remaining 8 bits are all zeros, resulting in zero.
  • For int: All significant bits are preserved, allowing the value 256 to be stored correctly.

output:

$ javac leftshift_operator.java
$ java leftshift_operator
256 0

c) Integer value assigned to floating type
d) Integer value assigned to floating type
View Answer

Answer: b

43. What is the numerical range of a char data type in Java?
a) 0 to 256
b) -128 to 127
c) 0 to 65535
d) 0 to 32767
View Answer

Answer: c
Explanation: In Java, the char data type is a 16-bit unsigned integer that uses 2 bytes of memory. It is used to store Unicode characters, such as special symbols, emojis, and more. The range of values it can represent is from 0 to 216 − 1, which is 0 to 65,535. Being an unsigned data type, char can represent only non-negative values, effectively doubling the upper limit compared to a signed type by excluding negative numbers from its range.

For signed integer types, the range is calculated using the formula:
−2n-1 to 2n-1 − 1,
where n is the number of bits used to store the value.

  13.         overload() 
  14.         {
  15.             this.x = 0;
  16.             this.y = 0;
  17.         }        
  18.     }    
  19.     class Overload_methods 
  20.     {
  21.         public static void main(String args[])
  22.         {
  23.             overload obj = new overload();   
  24.             int a = 2;
  25.             double b = 3.2;
  26.             obj.add(a, a);
  27.             obj.add(b, b);
  28.             System.out.println(obj.x + " " + obj.y);

  30.    }

a) 4 6.4
b) 6.4 6
c) 6.4 6.4
d) 6 6
View Answer

Answer: a
Explanation: For the method call obj.add(a, a), since a is of type int, the method defined at line 5 is executed. Similarly, for the call obj.add(b, b), since b is of type double, the method defined at line 9 is invoked. As a result, the values of x and y are set to 4 and 6.4, respectively.

output:

$ javac Overload_methods.java
